# 体素 RPG 第二阶段：森林演出与全职业技能特效

## 目标

在第一阶段 3D 森林篝火议会基础上，增加完整的职业技能演出、程序化环境音与技能音、角色动作、昼夜过场和关键事件镜头，同时保持规则引擎、多人协议、身份遮罩和经典 2D 不变。

## 已确认决策

- 深化现有森林营地，不新增地图、不提供 WASD。
- 覆盖全部现有 16 个职业。
- 当前行动者能看到自己的职业专属演出。
- 上帝模式、全知复盘能看到全部职业演出、施法者和目标。
- 其他玩家只能看到不暴露职业、施法者和目标的中性环境反馈。
- 增加森林、虫鸣、风声、篝火环境音和原创程序化职业技能音效。
- 不复制《我的世界》或其他游戏的声音、贴图、模型与商标元素。
- 不修改 Git、APK、规则引擎和多人消息协议。

## 事件与权限架构

新增纯数据层 `skillEffectModel.ts`。它把当前阶段、已经过权限裁剪的日志、当前客户端可见职业、玩家公开状态和视角权限转换为短生命周期 `SkillEffectEvent`。场景组件只能消费该事件，禁止直接读取完整 `godState`。

事件包含唯一 ID、回合、阶段、效果类型、可见等级、可选施法者/目标、颜色配置、音效提示、持续时间和镜头提示。事件分为三种可见级别：

- `neutral`：所有视角可见，只包含雾、风、火焰波动、通用冲击等中性反馈。
- `role`：当前行动者可见，允许显示自己的职业符号、施法轨迹和自己选择的目标。
- `omniscient`：上帝模式与全知复盘可见，允许显示全部施法者、目标和结果。

私密目标只能从当前客户端已经可见的日志中解析。普通玩家即使本地状态暂时包含真实职业字段，也不能因此获得专属事件。公开翻牌、自爆、骑士决斗、猎人开枪、白痴翻牌等公开事件可以向所有人播放对应职业演出。

首次进入 3D 或重连时，把现有日志标记为已见，只恢复当前阶段环境，不重播旧技能。新增日志才生成一次性事件，避免重复播放或通过重放顺序推断身份。

## 全职业视觉语言

- 狼人：暗红爪痕与低位雾流。
- 狼王：赤金威压环与猎击冲击。
- 白狼王：白焰爆裂与定向冲击。
- 血月使徒：血月遮罩与封印符文。
- 石像鬼：灰紫石化碎片与凝视射线。
- 预言家：蓝紫水晶环、星点与查验光束。
- 女巫：翠绿解药、紫色毒雾和药瓶轨迹。
- 守卫：蓝色方块护盾与六面屏障。
- 猎人：金橙弹道与后坐力闪光。
- 骑士：金色圣剑轨迹与决斗冲击线。
- 守墓人：青灰灵火与墓碑回响。
- 猎魔人：琥珀弓弦、符文箭和命中爆点。
- 丘比特：粉色双向连线与心形体素粒子。
- 奇迹商人：翠金符文、悬浮方块和技能转移轨迹。
- 白痴：青色翻牌护符与幸存波纹。
- 村民：投票、发言时的暖色勇气微光，不暗示额外能力。

普通未授权视角把上述效果统一替换为低饱和风压、篝火波动或环境雾，不保留职业色、专属形状、施法座位和目标连线。

## 场景演出

- `SkillEffects` 根据事件渲染复用几何体的粒子环、射线、护盾、符文和冲击波。
- `SceneDirector` 在允许聚焦的事件期间优先看向施法者或目标，结束后恢复发言者/总览镜头；用户手动接管仍有最高优先级。
- 角色增加待机呼吸、发言摆动、施法抬手、受击后仰和死亡过渡。
- 昼夜变化增加短暂天空混色、雾密度变化、火光增强和 HUD 阶段标题。
- `subtle / medium / intense` 控制粒子数量、阴影、动态光和镜头震动；低效果保留必要的可读反馈。
- 移动端限制同时存在的一次性事件数量，并关闭高成本动态光。

## 程序化音频

新增独立的 `VoxelAudioEngine`，只使用 Web Audio API 合成原创声音，不依赖外部音频文件：

- 环境层：滤波噪声模拟风、短噪声脉冲模拟篝火、稀疏正弦音模拟虫鸣。
- 技能层：振荡器、噪声包络和滤波器组合生成水晶、药水、护盾、弓弦、石化、圣剑、血月等提示。
- 音频在首次用户交互后解锁；浏览器拒绝时静默降级，不阻塞对局。
- 环境音和技能音分别开关，共享世界音量；配置持久化并兼容旧配置。
- 不把音效播放接入 TTS 队列，避免技能提示阻塞旁白和玩家发言。
- 未授权视角只播放中性声音，不通过音高、节奏或空间位置泄漏职业和目标。

## 数据流

`useGameRoomState` 提供阶段、权限裁剪日志、玩家和视角权限 → `useSkillEffectTimeline` 只处理新增可见日志并调用纯事件模型 → `SkillEffects`、`SceneDirector`、`VoxelAudioEngine` 消费同一已裁剪事件 → 事件到期后清理。

NPC 点击和技能提交仍通过 `worldTargetAtom → HumanInputPanel → resolveHumanInput / multiplayer ACK`。技能特效只是已有动作的表现，不产生任何提交能力。

## 验收

- 16 个职业均有数据驱动的专属视觉与音效配置。
- 当前行动者只看到自己的专属演出；上帝/全知视角看到全部；其他玩家只见中性反馈。
- 普通访客无法从颜色、声音、镜头、目标轨迹和重连重播推断隐藏身份。
- 昼夜过场、待机/发言/施法动作和事件镜头正常，手动镜头接管仍可恢复。
- 环境音与技能音可独立开关并调节音量；自动播放受限时安全静音。
- 低效果移动端维持可用，WebGL 或 Web Audio 失败均可降级。
- 类型检查、单测、生产构建、单人和多人 E2E 全部通过，依赖审计为 0 漏洞。
